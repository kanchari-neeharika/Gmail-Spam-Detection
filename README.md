**Objective**

The objective of this project is to create a machine learning model that will be able to classify emails as Spam or Ham, with a third category called Doubtful for low-confidence predictions.

**Tech Stack**

The programming language used for this project is Python, and the following libraries are used:
pandas
scikit-learn
matplotlib

**Steps Included**

1. The steps included in this project are as follows:
2. Loading the data
3. Encoding labels: Spam = 1, Ham = 0
4. Splitting data: train test split
5. Converting text data: TF-IDF
6. Training a Logistic Regression model
7. Classification: Spam/Ham/Doubtful

**Visualization Included**

Bar chart of Top 20 frequent words in spam emails
Using CountVectorizer + Matplotlib

**Analysis Included**

Training and testing accuracy
Confusion matrix for prediction results
Classification report
Word frequency analysis in spam emails

**Key Insights**

Logistic Regression classifier is suitable for spam detection
TF-IDF is helpful in improving the quality of the features
Frequent words in spam emails include 'urgent,' 'win,' 'free,' etc.
The 'doubtful' category is helpful in eliminating false predictions
